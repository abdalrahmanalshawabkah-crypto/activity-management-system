# نظام إدارة الأنشطة (Activity Management System)

تطبيق ويب متكامل لإدارة الأنشطة والفعاليات التربوية والدعوية والثقافية مبني باستخدام **Python Flask** و **SQLite** ومحرك **ReportLab** لتوليد تقارير الـ PDF بطابع إسلامي راقي وتصميم متجاوب تماماً مع الهواتف والأجهزة اللوحية (Mobile-First).

---

## 🌟 المميزات الرئيسية للنظام

1. **حارس الدخول العام (Global Login Guard & RBAC):**
   - حماية صارمة عبر `before_request` تمنع تصفح أي مسار دون جلسة نشطة.
   - فصل دقيق للصلاحيات بين المدير (`admin`) والمشرف (`user`).

2. **هيكل قاعدة البيانات المترابطة (SQLite `database.db`):**
   - يتم إنشاء قاعدة البيانات وجداولها (users, activities, staff, participants, expenses, system_contents, educational_materials, evaluations) تلقائياً عند التشغيل الأول مع بذور بيانات تجريبية.

3. **بنك الأفكار وميزة "استخدم هذه الفكرة" (Adopt Idea):**
   - استعراض الأفكار والتعليمات مع بحث فوري مباشر (Live Search) دون إعادة تحميل.
   - زر "استخدم هذه الفكرة" ينقل المشرف إلى نموذج إنشاء النشاط مع التعبئة الآلية لكافة الحقول.

4. **نموذج إنشاء النشاط المتقدم:**
   - تحقق صارم من البيانات وفرض القيم الافتراضية التلقائية ("لا يوجد" للنصوص و "0" للأرقام).
   - إضافة ديناميكية لصفوف الكادر، المشاركين، وبنود المصاريف.
   - معاينة موقع خرائط جوجل (Google Maps).

5. **محرك تقارير الـ PDF (ReportLab Engine):**
   - تصميم هندسي إسلامي بدون جداول جافة أو متداخلة.
   - ضبط دقيق للمسافات (Spacers) وهوامش الصفحة لمنع أي تداخل بصري.
   - تقرير رقمي موثق خالٍ من التواقيع التقليدية ومطابق للمواصفات الرسمية.

6. **لوحة تحكم تفصيلية وتقييم ميداني:**
   - إحصائيات الفروع، الكوادر، الفئات العمرية، ونموذج تقييم استراتيجي لمخرجات كل نشاط.

## 🔑 الحسابات الافتراضية للنظام

| الدور | اسم المستخدم | كلمة المرور | الصلاحيات |
| :--- | :--- | :--- | :--- |
| **مدير النظام** | `admin` | `admin123` | كامل الصلاحيات، لوحة الإحصائيات، سجل الأنشطة، إدارة المواد والأفكار |
| **مشرف عادي** | `user` | `user123` | إنشاء الأنشطة، سجل أنشطتي، تقييم الأنشطة، تحميل الـ PDF |

## 🚀 التشغيل المحلي (Local Development)

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل السيرفر:
```bash
python app.py
```
افتح المتصفح على: `http://localhost:5000` أو المنفذ المحدد.

## ☁️ خطوات الرفع السحابي (Deployment Guide)

### أ. الرفع على Render (Web Service):
1. قم برفع مستودع المشروع إلى GitHub.
2. أنشئ **Web Service** جديد على Render واختر المستودع.
3. الإعدادات المطلوبة:
   - **Environment:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
4. **لضمان حفظ قاعدة بيانات SQLite بشكل دائم:**
   - توجه إلى تبويب **Disks** في إعدادات الخدمة وأضف Persistent Disk بحجم 1GB ومسار `/opt/render/project/src/data`.
   - قم بتعيين متغير بيئة يوجه ملف `database.db` إلى القرص المستمر.

### ب. الرفع على Railway:
1. أنشئ مشروعاً جديداً عبر **Deploy from GitHub repo**.
2. سيتعرف Railway تلقائياً على ملف `Procfile` ويقوم بتشغيل `gunicorn app:app`.
3. يمكنك إضافة Volume دائم لملف `database.db` ومجلد المرفقات `uploads/`.
